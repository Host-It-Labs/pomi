# Contributing to Pomi

Thank you for proposing an improvement. Search existing issues first and keep
pull requests focused on one behavior or maintenance concern.

1. Fork the repository and create a topic branch.
2. Install dependencies with `pnpm install --frozen-lockfile`.
3. Add coverage at the cheapest reliable test layer.
4. Run `pnpm -r run build`, `pnpm lint`, and the relevant tests.
5. Complete the pull request template and disclose generated code or external
   assets.

Do not include credentials, exports, production data, private URLs, signing
files, Firebase project files, or third-party assets without provenance.

By submitting a contribution, you agree that it is licensed under the same
PolyForm Noncommercial License 1.0.0 terms as Pomi.

By participating, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Report
security problems through [SECURITY.md](SECURITY.md), not a public issue.
