# One warm workspace

Status: Accepted

Desktop and mobile combine intentions, compact Timer, and the complete Task workspace in one page. The accepted Midnight navy palette with blue Work, sage Break, and dark teal-green Long break accents supersedes the earlier soft-stone and warm graphite proposals. Wear and the website are excluded.

The latest user feedback chooses direct session-segment selection without a details popup, a centered large countdown, compact icon ETAs, five two-line desktop Task rows with keyboard paging, six intentions in two rows, content-sized sheets, and Description among basic Task fields. These replace earlier full-circle, separate Tasks page, centered editor, and Completed-subfilter decisions. DESIGN.md defines the resulting composition.

Tasks are available for every Timer type, with explicit filters preserved. The obsolete break-visibility preference is removed by migration; existing feature choices remain intact. New-account defaults enable core tools. Suggestion dismissals are validated account preferences and survive synchronization and export/import without changing feature state.

AI infrastructure has a separate admin-only Settings destination. User-facing Assistant preferences and backend authorization remain separate. Saves continue to use confirmed server state.

The task filter dropdown is 30 px wider than its trigger, with favorites first and emoji-only Sub-intentions. A thin All / Intention switch replaces favorite badges and follows Timer selections with strict matching; pagination remains centered. Sheet height is intrinsic, with More options inside the field area and management actions separate from Save.
