# Cascade Title-Derived Intention Slug Renames

Changing an Intention title regenerates its title-derived slug; unrelated edits never churn it, and collisions receive the lowest available numeric suffix. Archived Intentions continue to reserve their slugs. The rename cascades as one domain operation through current Tasks, Pinned Task state, active Timer and cached Watch state, statistics, timer logs, Task event snapshots, and every other current or historical slug reference so one Intention never appears split across old and new handles.
