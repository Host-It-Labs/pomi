# E2E ownership matrix

This matrix preserves the complete pre-revamp Playwright inventory after deletion. Main business behavior maps to executable specification sets and the eight-domain manifest; duplicate and narrow presentation rows are retained as historical expectations but are not claimed as one-for-one replacement coverage. Retained Playwright tests may mock browser or operating-system facilities but never Pomi backend APIs.

## Retained real-stack journeys

1. Account creation, authenticated reload, logout and login
2. Intentions Parent/Sub selection through recorded Timer
3. Primary Timer start, pause, add-five, undo and reset
4. Session extension through Break or Long break with persistence
5. Task create/edit through shared editor with reload persistence
6. Linked Task pin, Timer Intention reconciliation and completion
7. Recurring Task complete and undo/archive with successor preservation
8. Manual Task ordering persisted across refresh
9. Cross-client Task sync with other-user isolation
10. Cross-client settings sync affecting Timer behavior
11. Real Timer/Task activity visible in statistics and work logs
12. Accepted-action FIFO, delayed indicator, reconnect and reconciliation
13. Administrator export and complete user-data import
