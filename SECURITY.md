# Security policy

Only the latest release is supported with security fixes.

Do not open public issues for suspected vulnerabilities. Use GitHub's private
vulnerability reporting for this repository. If that feature is unavailable,
contact the maintainer through the private contact method listed on the GitHub
profile and request a secure reporting channel. Do not send secrets or exploit
details before a private channel is established.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. The maintainer will acknowledge a complete report within seven
days and coordinate disclosure after a fix is available.
